# 変異体ハーネス（退避したもの・未整理）

門番（`scripts/verifylib.py` ほかの `check_*`）が本当に効くかを試す道具です。
**動かすフォントをわざと壊して、門番が気づくかを見る**——気づかなければ
それが盲点で、門番を足す根拠になります。

例（ラウンド 12 の変異体 W3、これで「かな・漢字をドナーの描き方と
突き合わせる」門番が生まれた）:

```python
@mutant("W3", JP_REG, "the kana し mirrored left-to-right inside its own box "
                      "(the advance and the cell are kept)")
def W3(tf, src):
    mirror(tf, g(tf, "し"))      # 「し」を自分の箱の中で左右反転
    M.refit(tf)
```

送り幅・外接箱・インク面積・cmap がすべて保たれるので、当時の門番 56 本は
全部これを通していました。

`scripts/verifylib.py` などの docstring が参照している
「round 11, mutant D2」「round 12, mutant W3」は、ここの定義のことです。

## 位置づけ

- **ラウンド 9〜12 で実際に走らせたまま**の姿で退避しています。整理も
  リファクタもしていません（4 世代で `mutlib.py` は同一、`mutants10.py` /
  `mutants10b.py` は r10〜r12 で重複）
- **CI には入っていません。** `ruff check scripts/ tests/` も
  `pytest tests/` も `tools/` を見ないので、このコードは検査対象外です
- 生成物（変異させたフォント、計 276 MB）は**含めていません**。各変異体の
  ディレクトリに残る `.src` から作り直せます

## 動かす前に直す 2 行

`mutlib.py` の冒頭に、このセッション固有の絶対パスが 2 つ埋まっています。
**そのままでは動きません。**

```python
REPO = Path("/home/user/shoyu-code-pro-jp")          # リポジトリの場所
ENV  = (".../scratchpad/r52env.sh")                  # ドナーの環境変数を書いた sh
```

`REPO` は `HERE` から辿れますし、`ENV` は環境変数から取れば済みます。
意図的に直していません——検証せずに手を入れたコードを混ぜたくなかったためです。

## 走らせ方

```sh
cd tools/mutants/r12
python run.py list          # 変異体の一覧
python run.py W3 L1 F1      # 指定した変異体を作って門番にかける
```

出力は変異体ごとに `<ID>/mutant.otf` と `<ID>/verify.txt`（門番の全ログ）。
`CAUGHT` なら門番が捕まえた、`*** BLIND SPOT ***` なら素通り。

1 個につきフォント 1 枚を生成して門番一式を通すので、**287 個を全部走らせると
1.5 時間規模**です。PR ごとの CI には乗りません。
